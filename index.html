Projects

Things I've built end to end.

Each one is live, and each one has numbers I measured myself.

  • Quiver

    Go · HNSW · ARM64 NEON · WAL

    A vector database written in Go with no third-party dependencies. It has an HNSW index, a write-ahead log, snapshots, filtered search, an HTTP API and a web UI.

    • 0.99 recall@10 at 3,849 queries/sec per core on SIFT1M. That is about 75% of FAISS and 20% faster than hnswlib on the same machine.
    • Hand-written ARM64 NEON distance kernels, 2.5× faster than the compiled Go version.
    • Group commit in the write-ahead log took durable writes from 420 to 14,900 per second, with no acknowledged write lost across repeated kill -9 crashes.
    Live demo ↗GitHub ↗

  • HELIX

    Python · LLMs · PostgreSQL · Next.js

    A news pipeline that runs on its own. Every day it reads about 400 articles from 13 sources, summarises them with an LLM, ranks them for each reader and sends a personal email.

    • Brought a slow query from 8.5s to 3.7s by replacing an in-memory scan of 32k rows with a SQL anti-join and indexes.
    • Traced a silent outage to three causes, taking ingest from 5 articles a run back to about 420.
    Live site ↗GitHub ↗

  • Smart Emergency

    Python · TRL · QLoRA · GRPO

    A reinforcement-learning environment where an LLM agent triages and dispatches 911 calls across generated city maps. Its reward punishes shortcuts such as inventing unit IDs.

    • Fine-tuned Qwen3-1.7B with QLoRA (loss 2.32 → 0.31), then trained it further with GRPO against the environment.
    Hugging Face Space ↗GitHub ↗

  • AeroPrep

    Next.js · Express · Postgres · LLMs

    A mock-interview coach that runs practice interviews and gives you feedback on each answer. It works with any model provider, keeps each interview's token use small, and gives new users three free interviews.

    Live site ↗GitHub ↗
