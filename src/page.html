Case study · Meshery authorization

A permission system that updates itself.

110→0

Meshery's UI checked permissions against 110 UUIDs hardcoded in a 449-line file. Every new permission meant a hand edit, and a typo failed silently.

The keys are now generated from @meshery/schemas and validated at compile time. Sistent's PermissionProvider and PermissionShield tell a user why a control is disabled and which role unlocks it. The organization switcher only lists orgs the user can act in.
